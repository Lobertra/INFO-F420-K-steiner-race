Pruning degree-4 Steiner points

The old and the new method for the Euclidean k-Steiner tree problem

INFO-F420 – Computational geometry · Louis BERTRAND · 2026

This project is based on the paper An improved exact algorithm for the Euclidean k-Steiner tree problem by J. Lee, M. Brazil, C. Ras and D. A. Thomas (Computational Geometry: Theory and Applications, 2026). The report compares the old pruning method (Rhombus Test) and the new one (Trapezium Test and extended Rhombus Test), the race runs the two methods side by side, and the experiment measures the difference on 5,400 random instances.

How to run the programs

  • The race: click “Open the race” above, or open race/index.html in a web browser.
  • The experiment of the report (5,400 races): click “Run the experiment” above, or open experiment/index.html, then click “Run the experiment”. The results appear in a table and can be downloaded as a CSV file.
  • Nothing needs to be installed. If you open the files from the zip, keep the folder structure as it is, since the pages use relative paths.
