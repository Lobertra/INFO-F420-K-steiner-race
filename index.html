Pruning degree-4 Steiner points

The old and the new method for the Euclidean k-Steiner tree problem

INFO-F420 – Computational geometry · Louis BERTRAND · 2026

This project is based on the paper An improved exact algorithm for the Euclidean k-Steiner tree problem by J. Lee, M. Brazil, C. Ras and D. A. Thomas (Computational Geometry: Theory and Applications, 2026). The report compares the old pruning method (Rhombus Test) and the new one (Trapezium Test and extended Rhombus Test), and the web page runs the two methods side by side as a race.

Read the report (PDF) Open the race

How to run the programs

  • The race needs nothing to install. Open race/index.html in a web browser (or click “Open the race” above).
  • The experiment of the report needs Node.js. From the experiment folder, run node experiment.js > results.csv (about 40 seconds).
  • Keep the folder structure as it is, since the files use relative paths.
